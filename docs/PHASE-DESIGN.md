# Crestwright 相位模块设计记录

版本 1.2.1 · 2026-11-24

## 1. 参数来源

两段全通的频点与 Q 值来自项目所有者在 Pro-Q 4 中测试并确认的改订版预设。
该预设副本以 `verification/reference-preset-v3.ffp` 保存在本地，**不纳入
公开仓库**。预设中启用的全通频段为 Band 1、4
（`Shape=9`，`Slope=2`，`Gain` 对全通不起作用）。预设以 `log2(Hz)` 存储频率，
`2^9.965784 = 1000 Hz` 可验证该换算。

预设的公称 f0 是 40.068 / 183.340 Hz。两段二阶全通的相位相加后，屏幕上的
折返点是总相位过 -180° / -540° 的位置，并不等于单段 f0：直接使用公称值会
得到 29.8 / 246.5 Hz 的折返点，比 Pro-Q 更外扩。为匹配 Pro-Q 实测的
35.133 / 209 Hz，保持预设 Q 不变，反解出内部 f0 为 60.220 / 121.939 Hz。

| 预设频段 | 预设 log2(Hz) | 预设 f0 (Hz) | Q | 实现 f0 (Hz) |
|---|---|---|---|---|
| Band 1 | 5.32437801361084 | 40.067983877449 | 0.555777788162 | 60.219762230 |
| Band 4 | 7.51837825775146 | 183.340062190770 | 0.500000000000 | 121.938794260 |

级联顺序按频率从低到高排列；级联的乘积与顺序无关。

**关于 Clean-room：** 该 `.ffp` 预设由项目所有者本人创建，其中的频点、Q 值
和滤波器类型是所有者自己的设计选择，不属于第三方产品的测量数据或工厂预设。
`.ffp` 只是 FabFilter 的文件封装格式；本实现没有使用 FabFilter 的代码、DSP
算法、界面资源或任何工厂预设，滤波器本身是通用的双线性二阶全通公式。
因此原规格第 9 节的声明仍然成立：实现者没有接触第三方产品的测量数据或预设，
依据的是所有者自己的参数。预设副本和解析脚本仅保存在本地，不纳入公开仓库；
文档中只保留推导后的数值表，便于追溯。

## 2. DSP 结构

每段为双线性变换（RBJ）标准二阶全通：

```
w0    = 2π f0 / fs
alpha = sin(w0) / (2 Q)
a1    = -2 cos(w0) / (1 + alpha)
a2    =  (1 - alpha) / (1 + alpha)

H(z) = (a2 + a1 z^-1 + z^-2) / (1 + a1 z^-1 + a2 z^-2)
```

实现采用直接 II 型转置结构，系数与状态均为 `double`：

```
y  = b0*x + z1
z1 = b1*x - a1*y + z2
z2 = x    - a2*y          (b2 = 1)
```

- 零延迟：普通 IIR，无前瞻、无延迟线
- 纯全通：每段 `|H(e^jω)| = 1`
- `prepare()` 按采样率重算系数，之后不再分配内存
- 极点半径上限 0.9995：通过抬高 `alpha` 的下限实现
- 状态非有限（NaN/Inf）时自动 `reset()` 并输出 0

## 3. 深度档位

- 1x = 2 段级联一次；2x/3x/4x = 同一级联重复 2/3/4 次
- 四个档位的抽头**始终并行运行**，因此每个抽头的滤波器状态始终有效；
  切档只是输出端的交叉淡化，不会出现状态复位造成的瞬态
- 30 ms 线性交叉淡化：权重向量从当前值线性过渡到目标档位
- 淡化中途再次切档时，从当前权重重新开始 30 ms 过渡
- 代价：每声道固定 8 个双精度 biquad，实测 CPU 0.061%（48 kHz 立体声，4x）

48 kHz 下结果与 44.1 kHz 基本一致（最大差 0.001 ms），说明系数按采样率
重算后频率响应保持一致。

该曲线由两段全通自身的相位决定；1 kHz 以上保留少量群延迟，是这一配置的
固有特性。当前实现以改订版预设参数为准，不再以旧规格表作为验收目标。

### 4.2 其它指标

- 幅度：10 Hz–20 kHz 最大偏差 3.0e-7 dB（44.1 kHz）/ 2.9e-7 dB（48 kHz）
- 延迟：脉冲响应第一个非零样本在 n = 0（0 samples）
- 深度倍率（48 kHz，群延迟 ms）：20 Hz 处 14.277 / 28.554 / 42.831 / 57.108
- 切换连续性：1x→4x、1 kHz 正弦，淡化期间最大样本步进 0.128894，
  与正弦自身最大斜率 0.130806 基本一致，无样本级跳变
- 需要说明：30 ms 淡化期间叠加的是两个相位不同的全通输出，因此在部分频率
  会有短暂的幅度凹陷（1 kHz 最坏情况约 2.4 dB），这是“输出交叉淡化”本身的
  性质，不是爆音或状态复位。淡化结束后电平严格回到 0 dB
- 稳定性：注入 NaN 后输出立即有限并保持有限；长时间 4x 运行无溢出
- CPU：0.062% 单核（48 kHz 立体声，4x，4 遍级联，MSVC Release）

## 5. 输入级 transient shaper

整个处理链路的最前面（INPUT 之前）有一个固定、不可见的 transient shaper：

- 常开，无参数、无 UI、无 bypass
- 只提升 Attack，最大 +5%（增益 1.00 → 1.05，约 +0.42 dB）
- 立体声联动 RMS 包络：fast 0.5 ms attack / 30 ms release，slow 100 ms
- 稳态时增益回到 1.000；不削减 sustain、不做 makeup
- 零延迟，无内存分配
- 验证：稳态增益 1.00005，最大增益 1.050000，静音输出 0

复现：

```
cd verification
cl /O2 /std:c++17 /EHsc /Fe:test_transient.exe test_transient.cpp
test_transient.exe
```
