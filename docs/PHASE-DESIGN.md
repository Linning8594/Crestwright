## 1. 参数来源

六段全通的频点与 Q 值直接取自项目所有者在 Pro-Q 4 中测试并确认的改订版预设。
该预设副本以 `verification/reference-preset-v2.ffp` 保存在本地，**不纳入

级联顺序按频率从低到高排列；级联的乘积与顺序无关。

**关于 Clean-room：** 该 `.ffp` 预设由项目所有者本人创建，其中的频点、Q 值
和滤波器类型是所有者自己的设计选择，不属于第三方产品的测量数据或工厂预设。
`.ffp` 只是 FabFilter 的文件封装格式；本实现没有使用 FabFilter 的代码、DSP
算法、界面资源或任何工厂预设，滤波器本身是通用的双线性二阶全通公式。
因此原规格第 9 节的声明仍然成立：实现者没有接触第三方产品的测量数据或预设，
依据的是所有者自己的参数。预设副本和解析脚本仅保存在本地，不纳入公开仓库；
文档中只保留推导后的数值表，便于追溯。

## 2. DSP 结构

每段为双线性变换（RBJ）标准二阶全通：

```
w0    = 2π f0 / fs
alpha = sin(w0) / (2 Q)
a1    = -2 cos(w0) / (1 + alpha)
a2    =  (1 - alpha) / (1 + alpha)

H(z) = (a2 + a1 z^-1 + z^-2) / (1 + a1 z^-1 + a2 z^-2)
```

实现采用直接 II 型转置结构，系数与状态均为 `double`：

```
y  = b0*x + z1
z1 = b1*x - a1*y + z2
z2 = x    - a2*y          (b2 = 1)
```

- 零延迟：普通 IIR，无前瞻、无延迟线
- 纯全通：每段 `|H(e^jω)| = 1`
- `prepare()` 按采样率重算系数，之后不再分配内存
- 极点半径上限 0.9995：通过抬高 `alpha` 的下限实现
- 状态非有限（NaN/Inf）时自动 `reset()` 并输出 0

## 3. 深度档位

- 1x = 6 段级联一次；2x/3x/4x = 同一级联重复 2/3/4 次
- 四个档位的抽头**始终并行运行**，因此每个抽头的滤波器状态始终有效；
  切档只是输出端的交叉淡化，不会出现状态复位造成的瞬态
- 30 ms 线性交叉淡化：权重向量从当前值线性过渡到目标档位
- 淡化中途再次切档时，从当前权重重新开始 30 ms 过渡
- 代价：每声道固定 24 个双精度 biquad，实测 CPU 0.175%（48 kHz 立体声，4x）

## 4. 验证记录

验证程序 `verification/test_phase.cpp` 直接包含并编译发布用的
`Source/PhaseNetwork.h`，因此测量的是实际 DSP 代码，而不是单独的 Python 模型。

### 4.1 群延迟（1x，44.1 kHz）

| Hz | 实测 (ms) |
|---|---|
| 20 | 22.061 |
| 30 | 16.396 |
| 50 | 10.974 |
| 80 | 7.847 |
| 100 | 6.773 |
| 150 | 5.190 |
| 200 | 4.246 |
| 300 | 3.094 |
| 500 | 1.940 |
| 1000 | 0.955 |
| 2000 | 0.455 |
| 4000 | 0.203 |
| 8000 | 0.087 |
| 16000 | 0.041 |

48 kHz 下结果与 44.1 kHz 基本一致（最大差 0.002 ms），说明系数按采样率
重算后频率响应保持一致。

该曲线由六段全通自身的相位决定；1 kHz 以上保留少量群延迟，是这一配置的
固有特性。当前实现以改订版预设参数为准，不再以旧规格表作为验收目标。

### 4.2 其它指标

- 幅度：10 Hz–20 kHz 最大偏差 4.9e-7 dB（44.1 kHz）/ 5.8e-7 dB（48 kHz）
- 延迟：脉冲响应第一个非零样本在 n = 0（0 samples）
- 深度倍率（48 kHz，群延迟 ms）：20 Hz 处 22.063 / 44.126 / 66.189 / 88.253
- 切换连续性：1x→4x、1 kHz 正弦，淡化期间最大样本步进 0.130800，
  与正弦自身最大斜率 0.130806 基本一致，无样本级跳变
- 需要说明：30 ms 淡化期间叠加的是两个相位不同的全通输出，因此在部分频率
  会有短暂的幅度凹陷（1 kHz 最坏情况约 3.0 dB），这是“输出交叉淡化”本身的
  性质，不是爆音或状态复位。淡化结束后电平严格回到 0 dB
- 稳定性：注入 NaN 后输出立即有限并保持有限；长时间 4x 运行无溢出
- CPU：0.175% 单核（48 kHz 立体声，4x，4 遍级联，MSVC Release）
